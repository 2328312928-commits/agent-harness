# Agent Harness v0.1.0

## Highlights

- Complete Plan-Act-Observe-Reflect execution loop with bounded recovery.
- Durable task state, event trace, memory, and checkpoint store.
- MCP stdio and HTTP client with a five-tool bundled server.
- Docker sandbox with network, filesystem, capability, CPU, memory, PID, and time limits.
- DeepSeek, OpenAI-compatible, and deterministic offline providers.
- React console for runs, live Trace, tools, and evaluation results.
- 110-task benchmark suite and generated benchmark report.
- Docker Compose stack with API, web console, PostgreSQL, and Redis.

## Legacy Baseline

The original `100%` baseline was produced before successful-tool and strict-answer
checks were added. It is retained only as historical context and must not be used as
the current evaluation result. See `docs/evaluation-status.md`.

## Run

```bash
cp .env.example .env
docker compose up --build
```

Open <http://localhost:8080>.
