# Agent Harness v0.2.1

## Correctness

- Recovery exhaustion now sets task status to `partial`, never `completed`.
- Any unresolved failed tool remains in `unresolved_tool_failures`.
- Partial results cannot retain contradictory text such as “任务已完成”.
- Strict evaluation requires successful tool execution, answer checks, expected
  status, successful observations, and recovery counts.

## Security

- Production write APIs support `X-API-Key`.
- Public Demo mode forces `FakeProvider` and rate-limits anonymous tasks.
- Public Demo tool permissions exclude write and execute capabilities.
- Tool Playground is disabled by default and returns `403` in public mode.
- Evaluation API runs are capped in public mode.

The checked-in 110 tasks are a Runtime contract suite, not a public model-quality
leaderboard. The prior `100%` DeepSeek report was removed because its Grader was not
strict enough. See `docs/evaluation-status.md`.
