# Agent Harness v0.2.0

## Highlights

- Public Render demo for the runtime console and FastAPI service.
- Real `deepseek-chat` benchmark over 100 stable tasks.
- Provider-safe Function Calling names with registry name mapping.
- Valid assistant/tool message ordering across Act and Reflect phases.
- Bounded recovery now returns the final reflection instead of losing the task.
- Stable SQLite benchmark execution with WAL and busy timeout.
- Reusable GitHub Actions workflow for real-model evaluations.
